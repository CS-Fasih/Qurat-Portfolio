# Qurat-ul-Ain | QA Engineer Portfolio

A premium, dark-themed portfolio website for Qurat-ul-Ain — QA Engineer specializing in Manual Testing, API Validation, and AI-Assisted QA Workflows.

## Tech Stack

- **React** + **Vite** — Fast, modern frontend
- **Framer Motion** — Smooth scroll-triggered animations
- **Web3Forms** — Contact form API (no backend needed)
- **Vercel** — Hosting & deployment

## Features

- ✨ Dark premium design with lime green accents
- 🎭 Dynamic scroll animations & micro-interactions
- 📱 Fully responsive (mobile, tablet, desktop)
- 💬 Contact form with email delivery
- ⚡ Particle effects & cursor glow
- 📄 Downloadable resume
- 🔍 SEO optimized

## Getting Started

```bash
npm install
npm run dev
```

## Deployment

```bash
vercel --prod
```
